# Movie Analytics Dashboard | Excel

An interactive Excel dashboard for analyzing movie revenue, genre performance, IMDb ratings, and yearly trends.

**Tools:** Microsoft Excel, Pivot Tables, Pivot Charts, Slicers, and Data Visualization.

**Key Features**
- Total Movies and Gross Revenue KPIs
- Movie Revenue Trend by Year
- Revenue by Genre
- Top Stars by Average Revenue
- Interactive dashboard filters
